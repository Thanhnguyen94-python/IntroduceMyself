# Trang Tổng Quan (`/tong-quan`)

## Mục tiêu
Giới thiệu ngắn gọn, điểm nổi bật, hình ảnh đại diện chuyên môn SMT.

## Khối nội dung chính
1. Hero: tên, chức danh, slogan.
2. CTA: tải CV, liên hệ nhanh.
3. Highlights: thành tựu, năng lực nổi bật.
4. Ảnh tiêu biểu (xưởng/thiết bị/dự án).

## Nguồn dữ liệu
- Từ `content/pages` và phần tóm tắt từ `content/experience`.

## Definition of Done
- Mobile-first tốt.
- CTA hoạt động.
- Ảnh có alt text.
